# Style Guide
- Primary `#2563EB` (blue)
- Background `#F5F7FB`
- Text `#172033`
- Success `#15803D`
- Error `#B91C1C`
- Surface `#FFFFFF`

Text/background contrast is about 15:1 (AA pass; verify in WebAIM Contrast Checker).
Fonts: system sans-serif for heading and body; base size 16px.
Primary button: blue fill/white bold text. Secondary: white fill/blue border and text. Inputs: white with border, rounded corners, labels above. Error: red text near invalid field. CSS variables are at the top of `prototype/css/style.css`.
