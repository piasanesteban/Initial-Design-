# Project Brief: Student Task Tracker
## 1. The problem
Students juggle assignments and deadlines for different subjects. This app keeps task details, due dates, and progress in one place.
## 2. Users
| Role | Needs |
|---|---|
| Student | Add subjects and tasks, track deadlines, update progress, edit/delete own tasks. |
| Admin | View and manage user accounts. |
## 3. Database
Proposed database `student_task_tracker`, with 3 tables: `users` stores account details; `subjects` stores subjects connected to a user; `tasks` stores task details, deadlines, status, and subject link.
## 4. Must-have features
- Add subjects.
- Create tasks with title, description, and due date.
- View and filter tasks by subject/status.
- Update task details and progress.
- Delete unneeded tasks.
- Review upcoming deadlines.
## 5. Nice-to-have
- Highlight overdue tasks.
- Dashboard task summaries.
- Sort by deadline.
## 6. Similar apps
- Google Tasks: simple task list and completion state.
- TodoList: due dates and task status organization.
